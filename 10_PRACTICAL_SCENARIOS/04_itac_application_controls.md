# Scenario 4 — IT Application Controls

**Risk:** Invalid, incomplete, duplicate, unauthorized, or inaccurate transactions may be processed.

**Control objective:** Application rules validate transactions and ensure accurate, complete, authorized processing.

**Evidence:** Configuration, business requirements, test cases, transaction logs, rejected-record queues, interface reconciliations, exception reports.

**Scenario questions**
1. How do you test a mandatory-field validation?
2. How would you test duplicate invoice prevention?
3. What evidence supports an automated calculation?
4. How do you test interface completeness?
5. Why do ITGCs matter when relying on ITAC?
