# Scenario 6 — SOC 1 / SOC 2 Report Review

**Risk:** A third-party service provider's control gaps may affect the user entity's financial reporting, security, availability, or data processing.

**Control objective:** The organization evaluates independent assurance reports and performs its own complementary controls.

**Evidence:** SOC report, system description, auditor opinion, period, tests/results, exceptions, CUECs, subservice organization section, bridge evidence, vendor action plan.

**Scenario questions**
1. When would you request SOC 1 versus SOC 2?
2. What is Type I versus Type II?
3. What are CUECs?
4. What is carve-out versus inclusive method?
5. What if the report period does not cover the full review period?
6. Does an unmodified opinion mean no exceptions?
