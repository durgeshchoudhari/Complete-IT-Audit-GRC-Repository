# Ethical Use and Professional Boundaries

1. Never upload confidential employer, client, customer, employee, vendor, production, or regulated data to a public repository.
2. Use fictional or properly anonymized data, and verify that re-identification is not possible.
3. Do not claim a certification, audit engagement, system access, or control test you did not complete.
4. An auditor should preserve independence and objectivity; disclose conflicts and follow the applicable code of ethics and organization policy.
5. Audit evidence must be relevant, reliable, sufficient, and appropriately protected.
6. Frameworks are not interchangeable. Select criteria based on the engagement objective, scope, contractual obligations, jurisdiction, and current authoritative versions.
7. A SOC report is not a blanket certification. Review its scope, period, opinion, exceptions, complementary user entity controls (CUECs), and subservice organization treatment.
8. Python flags are analytics leads, not final audit conclusions.
