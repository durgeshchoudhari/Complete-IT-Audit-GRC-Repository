# Framework Comparison and Mapping

| Framework / report | Primary use | Typical lens |
|---|---|---|
| NIST CSF 2.0 | Cybersecurity risk outcomes | Govern, Identify, Protect, Detect, Respond, Recover |
| COSO ICIF | Internal control | Five components supporting objectives |
| COBIT | Governance and management of enterprise I&T | Governance and management objectives |
| SOC 1 | Service-organization controls relevant to user-entity ICFR | Financial reporting controls |
| SOC 2 | Service-organization controls against selected Trust Services Criteria | Security and other selected categories |
| SOX / ICFR | Statutory requirements for in-scope entities | Financial reporting control assurance |

A crosswalk is a navigation aid, not proof of equivalence. One control may support multiple frameworks, but evidence, scope, testing criteria, and conclusions must be evaluated separately.
