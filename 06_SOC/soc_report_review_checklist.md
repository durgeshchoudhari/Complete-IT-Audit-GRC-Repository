# SOC Report Review Checklist

- Identify report type: SOC 1 or SOC 2; Type I or Type II.
- Confirm service organization, system, services, locations, and report period.
- Read the independent service auditor's opinion and any qualifications.
- Understand system description, boundaries, and significant changes.
- Review control objectives / Trust Services Criteria included.
- Inspect tests performed, sample sizes where provided, and exceptions.
- Understand management responses and remediation.
- Identify subservice organizations and carve-out vs inclusive treatment.
- Identify CUECs and map each relevant CUEC to a user-entity control owner.
- Check whether report period leaves a gap before the current date; obtain bridge letter or other evidence where appropriate, while recognizing its limitations.
- Assess complementary subservice organization controls where relevant.
- Determine whether the report covers the service and risk relied upon; request additional evidence if not.

A bridge letter does not extend the auditor's testing period or replace a current report.
